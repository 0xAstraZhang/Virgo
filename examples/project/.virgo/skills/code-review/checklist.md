# Checklist

- Python: mutable default arguments, bare `except`, unclosed files, `is` vs `==`, timezone-naive datetimes.
- JavaScript/TypeScript: unawaited promises, `==` vs `===`, unchecked `any`, missing `key` props.
- SQL: string-built queries (injection), missing indexes on new filters, unbounded queries.
- General: secrets in code, logging of personal data, off-by-one ranges, unhandled empty inputs.
