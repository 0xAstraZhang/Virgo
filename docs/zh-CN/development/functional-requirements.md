# 叶级功能需求

[文档中心](../README.md) · [公理设计](axiomatic-design.md) · [验收证据](functional-acceptance.md) · [English](../../en/development/functional-requirements.md)

以下将 FR1–FR9 分解为可观察的结果。叶级编号表示需求，不表示 Python 包，也不宣称功能已经独立。对应 DP 描述可选择或调整的机制、策略。文件路径定位实现；[验收映射](functional-acceptance.md)给出代表性的可执行检查及其边界。

验收条件描述要求的行为。其中，压缩历史的结构保留不能证明任意模型响应下的事实记忆率或任务成功率。

## FR1 — 模型交互

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR1.1** | 获得规范化的流式文本、推理、工具调用与终态 | **DP1.1：** `ai/providers/*` 中的提供商适配与流规范化 | 等价协议夹具产生预期消息和停止/错误分类；取消后停止消费 |
| **FR1.2** | 使用指定账号，不借用其他提供商的凭据 | **DP1.2：** 凭据查找、OAuth/API 认证、端点绑定 | 账号/端点选择使用匹配凭据；被拒凭据不静默切换到另一个身份 |
| **FR1.3** | 选择可用模型及其支持的推理强度 | **DP1.3：** `ModelRegistry`、目录发现/缓存、强度映射 | 选定模型/强度进入请求；失败的选择保留当前配置 |
| **FR1.4** | 以运行时可处理的形式表达模型失败 | **DP1.4：** 提供商错误分类与规范化诊断元数据 | 可重试、上下文超限、能力不支持、致命失败与取消保留各自含义 |

## FR2 — 授权与资源边界

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR2.1** | 仅允许有效策略授权的资源操作 | **DP2.1：** 拒绝优先 `PermissionPolicy`、执行模式选择与绑定上下文 | 获准操作成功；被拒文件/网络操作产生显式结果且不扩大模式 |
| **FR2.2** | 在支持主机上限制模型启动的任意命令 | **DP2.2：** 原生 Shell 后端与进程启动策略 | 原生主机套件验证声明的文件系统/网络边界；Broker 夹具不能证明该边界 |
| **FR2.3** | 获取并应用针对具体资源的用户授权 | **DP2.3：** 审批/授权作用域、持久化与修订绑定 | 授权覆盖所请求操作/资源；拒绝、参数变化与无关任务不能复用授权 |
| **FR2.4** | 对高危命令和不可用的原生边界获取显式决定 | **DP2.4：** 风险分类与单次操作确认 | 拒绝阻止分派；单次授权不改变会话模式，也不重放可能已启动的 payload |
| **FR2.5** | 使项目控制的可执行配置遵守用户的信任选择 | **DP2.5：** 配置过滤、项目信任与 MCP 配置指纹 | 不可信项目的 hooks/providers/extensions 不能覆盖可信设置或获得可执行授权 |

## FR3 — 文件、命令与结果

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR3.1** | 读取、定位和修改目标文件 | **DP3.1：** Broker 文件工具、路径策略、匹配与原子替换 | 目标内容被修改或返回；越界与歧义编辑保持文件原样 |
| **FR3.2** | 执行命令并观察完成、失败或取消 | **DP3.2：** Shell 选择、执行上下文、进程监管 | 结果描述实际执行；取消和清理遵守选定进程契约 |
| **FR3.3** | 取回长输出，同时限制模型/UI 载荷大小 | **DP3.3：** `OutputStore`、字节上限、分页/检索与保留策略 | 来源会话可读取有界引用；分页保留有效 UTF-8 和访问作用域 |

## FR4 — 任务推进与控制

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR4.1** | 从模型决策经工具结果持续推进到最终回答 | **DP4.1：** Agent 循环、Schema 校验与工具调度 | 无效调用返回错误且不分派；并发完成不破坏逻辑调用顺序 |
| **FR4.2** | 遵守转向、取消与配置的工作上限 | **DP4.2：** 转向/跟进队列、轮次上限、共享 `RequestBudget` | 用户输入在下一个允许的边界送达；取消或预算耗尽阻止后续工作 |
| **FR4.3** | 仅按声明的恢复条件重试或切换模型 | **DP4.3：** 重试次数/等待预算、备用模型与重放限制 | 可重试失败遵守上限；可能已经开始的宿主执行阻止不安全自动重放 |

## FR5 — 状态、归属、上下文与用量记录

这些结果有不同的验收条件，不是一个可统一调整的“会话/压缩”功能。

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR5.1** | 恢复保存的对话历史与分支，不静默丢失内容 | **DP5.1：** `SessionStore` 记录格式、锁与断尾修复规则 | 恢复当前分支；断尾修复保留有效记录；权威存储写入失败阻止继续执行并保留未保存历史 |
| **FR5.2** | 将异步工作和证据归属到来源对话 | **DP5.2：** `ExecutionOrigin`/`BranchSource` 捕获与路由 | 切换可见会话不会将子任务结果、权限或证据转移给其他所有者 |
| **FR5.3** | 向模型提供适用指令及当前工具/上下文契约 | **DP5.3：** 提示组装、项目指令选择、请求预处理 | 按角色选择的指令进入请求；普通轮次保持追加式前缀；权限变化更新适用边界 |
| **FR5.4** | 在模型上下文限制内持续使用长对话 | **DP5.4：** 压缩触发/目标预算、尾部选择、裁剪和摘要策略 | 工具对与保留尾部保持有效；成功检查点可恢复；取消/失败不以不完整摘要替换历史。事实保留与任务质量需另行模型评测 |
| **FR5.5** | 追溯记录的请求配置并正确汇总已报告用量 | **DP5.5：** 请求头、辅助调用记录、分支用量汇总 | 请求头反映有效设置；重试/辅助/子任务用量在对应作用域计入一次。这不等于账单对账 |

## FR6 — 失败证据

存储证据、授权查询、将其作为模型输入投递是不同功能。投递证据可以有意影响后续决策；记录失败不应制造新的执行结果。

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR6.1** | 捕获有用的失败身份和原因，同时限制私有数据 | **DP6.1：** 捕获、脱敏、字段允许列表、大小上限 | 保留错误 ID/原因；凭据和排除的载荷不进入投影证据 |
| **FR6.2** | 独立于会话持久化保留可查询诊断 | **DP6.2：** 诊断数据库、去重、应急报告 | 已保存记录可查询；诊断写入/报告失败经兜底路径保留原故障，不损坏会话历史 |
| **FR6.3** | 经可用查询工具只读取当前运行时获准的证据 | **DP6.3：** `DiagnosticAccess` 作用域/分页、声明的查询工具选择 | 外部错误 ID 仍不可访问；每条查询指引使用当前运行时实际暴露且已声明的工具；缺少能力时不虚构工具 |
| **FR6.4** | 在既有请求边界和压缩之后提供相关证据 | **DP6.4：** 待投递证据、检查点投影、投递时机 | 证据到达所属运行时；单独报告故障不触发额外模型轮次；检查点保留可用查询引用 |

## FR7 — 委派与后台工作

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR7.1** | 用独立对话和显式继承的上限执行、复用子任务 | **DP7.1：** 子运行时、`SubagentStore`、角色/工具选择、轮次/强度设置 | 子历史隔离，可复用状态支持恢复，继承的权限/预算/取消限制保持有效 |
| **FR7.2** | 在正确对话中查询、取消和收集异步工作 | **DP7.2：** `JobManager` 生命周期、任务工具、按来源投递通知 | 任务到达终态；结果查询遵守归属；完成通知送达来源会话 |

## FR8 — 扩展能力

扩展注册是增加行为的机制。其安装的具体功能分别具有各自的结果要求。

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR8.1** | 增加配置的工具和事件行为，隔离加载失败 | **DP8.1：** `ExtensionAPI`、注册归属、优先级与 setup 回滚 | setup 失败撤回所属注册；其他能力与核心启动仍可用 |
| **FR8.2** | 发现并应用指定技能指令 | **DP8.2：** 技能发现、优先级与显式调用 | 选中指令进入请求，不读取任务允许范围外的资源 |
| **FR8.3** | 调用配置的外部服务并报告连接/分派结果 | **DP8.3：** MCP 传输、配置绑定、工具 Schema 与结果投影 | 配置的服务暴露有效工具；服务不可用不阻断无关启动；结果保留归属与输出上限 |
| **FR8.4** | 跨对话边界维护准确的任务清单 | **DP8.4：** Todo 校验、持久更新、压缩周期投影 | 有效更新替换清单；无效更新保持原样；未完成项跨压缩/恢复保留。清单不调度执行 |
| **FR8.5** | 使用可用且获准的能力检索或获取信息 | **DP8.5：** 宿主/客户端能力规划、提供商限制与回退策略 | 请求的能力可用或明确不可用；回退不重复已开始的宿主工作 |
| **FR8.6** | 请求用户决定，并区分回答、拒绝、超时与取消 | **DP8.6：** `ask_user` 选项、交互状态与超时策略 | 回答保留用户意图；非交互模式报告未回答；取消或无人值守问题不虚构决定 |

## FR9 — 用户与程序接口

呈现与获取决定是不同功能。布局不同的适配器可以保留同一个输入契约；移除回答能力则改变可用功能。

| 叶级 FR | 要求的结果 | 对应 DP | 验收边界 |
| --- | --- | --- | --- |
| **FR9.1** | 在选定交互界面显示对话进展与结果 | **DP9.1：** TUI/REPL 渲染、转录投影、事件观察 | 流式和终态结果保持正确运行归属；视图变化保留对话状态 |
| **FR9.2** | 向非交互调用方返回可用结果 | **DP9.2：** Print/text/JSON 输出适配器 | 输出遵守请求格式；并发 JSON 记录完整且可解析 |
| **FR9.3** | 将命令和普通用户文本路由到对应操作 | **DP9.3：** 命令解析、会话/运行时门面方法 | 有效命令到达处理器；转向/跟进文本不被误分类；无效命令保留当前会话 |
| **FR9.4** | 通过显式声明能力的输入适配器收集决定 | **DP9.4：** `UI` 确认/输入契约与适配器选择 | 相同请求与回答在支持的适配器上保留审批结果；缺少确认能力时阻止交互提权 |
| **FR9.5** | 按所选语言提供受支持的界面文本 | **DP9.5：** 会话级翻译器与语言资源 | 工具/帮助/审批文本使用所选语言且占位符匹配；回答语言指引仍遵循用户请求 |

## 使用目录

提出功能影响结论时，应说明叶级 FR、调整的 DP、固定条件与可观察的验收结果。单个夹具的测试只证明该限定场景，不证明对所有 DP 独立。共享预算仍是多个功能共同受限的显式资源约束；本目录不会为了消去矩阵元素而给各功能另设预算。

[功能验收](functional-acceptance.md)列出代表性测试、实际受控变化及结论的适用边界。
