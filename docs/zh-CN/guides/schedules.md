# 定时任务

[文档首页](../README.md) · [English](../../en/guides/schedules.md)

## 创建与管理

输入 `/schedule`，依次填写标题、任务正文、定时类别和时间，检查摘要后保存。创建过程不调用模型；执行时，保存的正文才会作为提示交给 Agent。手动创建的任务默认持久化到工作空间的 `.virgo/schedules.json`。

`/schedules` 打开任务工作页。选中任务后可阅读完整正文、查看下次执行时间、编辑或删除；删除需要确认。全屏列表中用方向键移动、Enter 打开、`n` 新建、Esc 返回。长详情可滚动；正文编辑用 Enter 换行，Ctrl+S 确认字段。确认字段不等于保存整个任务，仍需在最后摘要中确认。

两个命令均不接受参数，并等待当前模型运行结束。逐行模式提供编号选择；多行输入用单独一行 `.` 结束，`/cancel` 取消，编辑时直接输入 `.` 保留原文。非交互方式，例如 `virgo -p /schedules`，只打印列表或用法，不等待输入。

只修改标题或正文会保留下次执行时间；选择新规则时重新计算，但保留任务 ID。旧表单不能覆盖其他会话的修改、删除，或已经完成的单次任务。

## 定时类别

| 类别 | 输入 | 行为 |
| --- | --- | --- |
| 单次 | 未来日期时间，或 `+10m` 等相对值 | 执行一次 |
| 间隔 | 正整数分钟或小时，可指定首次时间 | 按实际经过的时间重复 |
| 每天 | `HH:MM` | 匹配本地时刻 |
| 每周 | 星期几和 `HH:MM` | 匹配本地星期与时刻 |
| 自定义 cron | 五段：分、时、日、月、星期 | 按本地时区匹配表达式 |

向导显示系统本地时区，单次日期时间可以带 UTC 偏移。间隔按实际经过的分钟计算，包括跨夏令时变化，支持每 7 分钟、每 25 小时等周期。

未指定首次时间时，从最终保存时刻开始等待一个间隔，摘要中的时间为预估值。指定首次时间后，之后各次沿原始节奏递推，不因执行耗时或轮询延迟漂移。调度检查延迟时最多投递一次，然后将下次时间推进到未来。

## 持久化与重启

**Virgo 必须保持运行，任务才会触发。** 此功能不安装系统 cron 或后台服务。

重启后，间隔任务跳过错过的次数并继续原节奏，cron 不补跑错过的时刻。已过期且持久化的单次任务会在之后的调度检查中执行一次。同一 Virgo 进程中，同一工作空间的持久化任务由多个会话共享，并只有一个投递所有者；不同 Virgo 进程之间不协调投递。

未完成的新建或编辑流程被取消时，已保存任务不变。全屏任务工作页打开期间，后台审批会等待返回对话后再显示。

## 模型工具接口

`schedule` 工具支持 `add`、`list`、`get`、`edit` 和 `cancel`：

- `add` 接受 `prompt`、可选的 `title` 和 `persist`，以及 `at`、`cron`、`interval_minutes` 三种规则之一。间隔还可以指定 `start_at`。
- `list` 返回 ID、类别、时间和标题；使用 `get` 加 `id` 获取完整正文。
- `edit` 修改指定字段。更换间隔时需要提供完整的新时间规则，不能只传 `start_at`。
- `cancel` 按 `id` 删除。

模型创建任务的 `persist` 默认是 `false`。旧任务文件无需手动迁移；没有标题时，使用正文首个非空行作为显示标题。新时间字段不保证可由旧版 Virgo 写入，避免让不同版本交替修改同一任务文件。
