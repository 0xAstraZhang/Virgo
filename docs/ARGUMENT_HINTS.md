# 命令参数提示

完整输入命令名或完成命令补全后，输入框以灰色显示参数语法。提示只是显示内容，不会写入正文、应用复制、历史或请求；方向键不会接纳提示。Enter、Tab、命令菜单和模型选择器保持原有行为。

## 显示规则

- `/model`、`/model `、`/model   ` 均显示 `[provider/id]`；输入实际参数后隐藏，删除参数后恢复。
- 仅在编辑器聚焦、无选区、光标在文档末尾、无换行且没有软换行时显示。未知命令和无提示的命令不显示。
- 保留真实光标单元格，剩余提示按终端单元格宽度裁剪；不改变文档换行、输入框高度或滚动范围。中文提示也按单元格裁剪。
- 历史召回仍不打开命令菜单。提示根据当前会话注册表实时解析；切换工作空间后使用该工作空间的命令定义。
- 注册命令优先于同名 Prompt 模板，包括没有提示的第三方覆盖命令。Prompt 模板统一显示 `[arguments]`。
- 本次范围为注册命令和 Prompt 模板；`/skill:name` 属于输入钩子语法，本次不增加其提示或菜单项。plain REPL 不增加提示。
- 复制保证适用于 Virgo 管理的复制路径；终端自身对屏幕字符的选择由终端控制。

## 扩展接口

```python
api.register_command("review", handler, "Review code", argument_hint="[path]")
```

`argument_hint` 默认为空字符串，是仅限关键字参数；`Commands.register` 和 `Command` 同样支持此参数。旧位置参数（包括 `concurrent`）保持兼容。提示是纯文本，方括号不解析为 Rich 标记；换行和制表符显示为空格。未声明提示的扩展不推测参数。
