# 定时任务

工作页的布局和实现范围见 [终端 UI 优化方案](designs/terminal-ui.md)。

## 手动创建与管理

输入 `/schedule`，依次填写标题、任务正文、定时类别和时间，检查完整摘要后选择“保存”。
这个流程不调用模型；保存的正文在任务触发时作为新提示交给模型执行。
标题独立于正文保存，手动新建的任务默认持久化到当前工作目录的 `.virgo/schedules.json`。

输入 `/schedules` 打开独立的任务工作页，按 **标题、执行频率、下次执行时间** 三栏展示任务。
页面标题只显示“定时任务”，列表不显示内部 ID、任务数量或运行前提标注。
使用上下方向键选择、Enter 打开详情、`n` 新建任务、Esc 返回对话。
返回列表时保留选择与滚动位置；新建后选中新增任务，删除后选中邻近项。
长标题在列表中截断，详情保留全文；缩小终端时三栏保持对齐，频率和日期可在各自列内换行。
详情显示完整正文、下次执行时间及持久化状态，可以编辑或删除；删除前需确认。
PageUp/PageDown 滚动详情，Ctrl+Home 回到顶部，Esc 返回或取消当前流程。
全屏正文编辑中 Enter 换行，Ctrl+S 确认正文，然后继续向导；此时尚未保存任务。
切换会话会保留各会话自己的表单草稿。最后确认之前取消，不产生任何变更。

编辑默认“保持原定时规则”：只改标题或正文不会重置下次执行时间。
选择新规则则重新计算时间，任务 ID 不变。任务已被其他会话修改、删除，或单次任务已执行时，
旧编辑表单不能覆盖这些变更；重新打开列表后再编辑。

两个命令均不接受参数；例如 `/schedules 每天上午9点…` 会显示用法，不会创建任务。
模型工作期间，命令按现有命令队列等待执行。

plain 模式提供编号选择和文本向导。多行正文逐行输入，用单独一行 `.` 结束，
`/cancel` 取消；编辑时直接输入 `.` 保留原正文。非交互模式只打印列表或用法，不等待输入。
例如 `virgo -p /schedules` 输出任务列表；使用 `--mode json` 时输出 `command_result` 记录，其 `text` 字段包含列表和用法。

## 周期和时间

| 类别 | 设置 | 执行频率列 |
|---|---|---|
| 单次 | 未来日期时间，如 `2027-01-20 09:00`；也接受 `+10m` | 单次 |
| 每 n 分钟／小时 | 正整数 n，可指定首次日期时间 | 如 `每 7 分钟`、`每 25 小时` |
| 每天 | `HH:MM` | 如 `每天 09:00` |
| 每周 | 一个星期几及 `HH:MM` | 如 `每周 周一 09:00` |
| 自定义 cron | 五段表达式：分、时、日、月、星期 | 自定义 cron 及原始表达式 |

下次执行时间独立显示为 `MM/DD HH:MM`；跨年时包含年份，完整时间及时区可在详情查看。

向导和详情展示系统本地时区。每天、每周、cron 按系统本地时刻匹配；单次日期时间可带 UTC 偏移。
间隔按实际经过的分钟数计算，包括跨夏令时切换；支持如每 7 分钟、每 25 小时，
不受 cron 字段边界限制。日期必须在系统能表示的范围内。

间隔任务未指定首次时间时，从最终保存时刻开始等待一个间隔；确认页中的时间是预估值。
指定首次时间后，之后各次始终从首次时间递推，不因执行耗时或轮询延迟漂移。
运行期间检查延迟时最多投递一次，并将下次时间推进到未来，不连续补发多次。

**Virgo 必须保持运行，才能触发任务。** 这里没有安装系统 cron 或后台服务。
重启时跳过已错过的间隔，沿原节奏继续；cron 不补跑错过时刻。
单次任务保留已有行为：保存的执行时间已过时，在恢复后的调度检查中执行一次。
持久化任务在同一进程、同一工作空间的多个会话间共享，并由一个会话负责投递；
不提供多个独立 Virgo 进程之间的投递协调。

## 模型工具与存储兼容

`schedule` 工具保留 `add`、`list`、`cancel`，新增 `get` 和 `edit`：

- `list` 返回 ID、类别、时间和标题；使用 `get` 加 `id` 获取完整正文。
- `add` 接受 `prompt`、可选 `title`、`persist`，以及 `at`、`cron`、`interval_minutes` 三者之一。
  间隔可另传 `start_at`（未来 ISO 日期时间）；默认一个间隔后首次执行。
- `edit` 接受 `id` 和需要更新的字段。仅改 `title`／`prompt`／`persist` 保留节奏；
  改时间时需提供完整的新规则，不能只传 `start_at` 而省略 `interval_minutes`。
- `cancel` 按 `id` 删除。模型创建的 `persist` 仍默认为 false，与原接口一致。

旧文件无须手动迁移。无标题任务使用正文首个非空行作显示标题，正文不变。
能明确识别的旧 cron 显示为每天／每周；复杂表达式保留“自定义 cron”标签。
间隔任务以分钟存储周期，以 epoch 秒存储首次和下次时间；更新后的文件仍使用原有原子替换写入方式。
包含新字段的文件不保证能被旧版本 Virgo 读取，升级后不要交替使用旧版本写入同一任务文件。
